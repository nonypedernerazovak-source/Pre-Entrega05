Agencia de Viajes — Paquete de Viajes
## Descripción
Este proyecto consiste en el desarrollo de un modelo de datos utilizando JavaScript para representar paquetes de una agencia de viajes.
Se creó la clase PaqueteViajes, que permite almacenar y organizar la información principal de cada paquete turístico, como el destino, la cantidad de días, el precio y la cantidad máxima de cupos disponibles.

## Clase PaqueteViajes
La clase contiene las siguientes propiedades:
id: identificador único del paquete.
destino: destino turístico del paquete.
dias: cantidad de días del viaje.
precioUSD: precio del paquete expresado en dólares.
cuposMaximos: cantidad máxima de personas que pueden reservar el paquete.
## Ejemplo de datos
Un paquete puede contener información como:
Destino: The United Kingdom
Lugares: Londres, Escocia
Atracciones: Abadía de Westminster, Castillo de Edimburgo
Duración: cantidad de días
Precio: expresado en USD
Cupos: cantidad máxima de pasajeros
